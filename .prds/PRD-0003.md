# Summary
An opt-in `--direct` mode, in the style of mosh: bootstrap over ssh as today, then move the session to a
direct QUIC connection through iroh when UDP gets through, and stay on the ssh pipe when it doesn't.
Parked until UDP support lands; the ssh transport remains the product's guarantee.

# Problem
Every stream rides one ssh TCP connection. One lost packet stalls every stream at once, a
single stream's throughput is capped by window ÷ round trip, UDP and DNS suffer from TCP's
retransmission delays, and a network change drops the session. QUIC fixes all four: per-stream flow
control, datagrams, and connection migration.

# Goals
1. A direct path that beats the ssh path on lossy or high-RTT links and survives network changes.
2. No regression for anyone who doesn't opt in: same relay, same push size, same behavior.
3. Silent fallback to ssh whenever UDP is blocked.

# Technical Approach
The relay offers an iroh endpoint over the established ssh session (endpoint id plus direct
addresses). The client dials it, pinning the key it received over ssh, and keeps the ssh pipe open as
the fallback. Streams map onto native QUIC bi streams, not onto the mux inside one QUIC stream,
which would bring head-of-line blocking back. UDP rides QUIC datagrams.

# Assumptions
- Without n0's relay servers, hole punching needs some other channel to coordinate the two ends.
  Whether iroh can coordinate over the ssh session (custom transports, or direct addresses
  alone) is unverified; T-006 answers it. Without that, `--direct` works only when one side can
  reach the other's UDP port directly.

# Constraints
Spike on 2026-10-17 (iroh 1.3, `default-features = false`, `tls-ring`, the relay profile): a minimal
relay-shaped endpoint came out at 5.07 MB against today's 605 KB relay (2.39 MB against 299 KB
gzipped). ring and blake3 compile C, so `rust-lld` alone can't build it: x86_64 built with clang
standing in for the musl C compiler, and aarch64 failed on blake3. cargo-zigbuild is the likely
answer, as a new CI dependency for this variant only.

# References to Code
- `crates/sshunnel-mux`: the stream semantics a QUIC backend has to match.
- `src/session.rs`: the ssh session the handshake extends.
- `src/bootstrap.rs`: relay selection, which gains the direct variant.

# Non-Goals (MVP)
- Replacing the ssh transport, or making UDP the default.
- n0's discovery service or relay servers.
- Plain quinn without iroh: the same C dependencies, and the remote must accept inbound UDP.
