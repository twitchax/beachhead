# PRD-0009 log

## Rulings -- 2026-10-28

Decisions made while the plan ran, beyond what the PRD or the plan said. Each gives the reason,
and what it costs if it's wrong.

- **`sudoers::script` keeps its signature and takes the uid from the process** (the PRD). Adding a
  uid parameter would change a public signature in a patch release. The script is already for
  whoever runs it, since it refuses `AlreadyRoot` and its answers come from this process's probe.
  Cost: a caller passing another user's name gets a line for its own uid, labeled with that name.
- **`doc-check` runs with `--all-features`**, for parity with the `clippy` task, so a feature-gated
  module's docs can't hide a warning. Cost: a few seconds per gate run.
- **The `sudoers` signal test can't pass vacuously** (T-003's review). Before it takes its skip, it
  asserts the host really refuses before probing: root, or a `/usr/local/bin` others can write.
  On a host where `sudoers` should have probed, an early exit fails it. Cost: a stricter test that
  fails loudly on a misconfigured CI host.
- **The help test checks both sentences of `--check`'s exit paragraph**, unwrapped (T-003's
  review). Rewrapping the sentence had dropped the second half from the assertion.
- **`StopSignal::ready` takes and returns `self`** (T-004's review), used as
  `StopSignal::new()?.ready()`. A borrowing `ready` tripped `unused_self`, and the first fix only
  dodged the lint. Its doc now claims only that `forward` announces through a registered signal:
  `session::ready_line` stays public, and `route` prints it after registering its own handlers.
- **clap's `string` feature** (T-004). `completable()` copies `Cli::command()`'s name and version,
  which are owned strings there. The feature adds no crate.
- **The visudo test's guard is name-keyed** (`root ALL=(ALL) ALL`, the final review). A `#uid`
  guard made the test skip on a visudo that rejects `#uid`, the one case it exists to catch.
