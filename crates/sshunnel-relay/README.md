# sshunnel-relay

The remote half of [sshunnel](https://github.com/twitchax/sshunnel): a small static binary the client pushes over SSH, which dials TCP on the client's behalf.

This crate is sshunnel's, and its interface follows sshunnel's needs; you would not normally run it by hand.
See the [main README](https://github.com/twitchax/sshunnel) for what sshunnel does.
