# sshunnel-mux

The wire protocol and stream multiplexer that [sshunnel](https://github.com/twitchax/sshunnel)'s client and relay share.

This crate is sshunnel's, and its API follows sshunnel's needs rather than a general-purpose multiplexer's.
See the [main README](https://github.com/twitchax/sshunnel) for what sshunnel does.
